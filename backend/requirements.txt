# Pinned to exact, already-tested versions rather than open ranges (>=) --
# a security audit found ranges meant a fresh install on a new machine could
# silently resolve to whatever's newest at that moment, including a future
# release nobody here has actually run against this codebase. Concretely
# relevant given axios (a frontend dependency) had two malicious versions
# published in March 2026 via a compromised maintainer account -- a pinned
# version can't pull in a release like that without someone deliberately
# bumping the pin first.
#
# Security patches now require a deliberate version bump instead of applying
# automatically -- Dependabot (.github/dependabot.yml) is configured to open
# a PR whenever a pinned version here has a newer release, especially ones
# with a security advisory, so patches still surface promptly; they're just
# reviewed as a diff rather than silently applied on the next install.
